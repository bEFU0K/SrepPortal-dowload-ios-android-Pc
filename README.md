## 🚀 Начало работы

1. Перейди на **[srepportal.craft-host.ru](https://srepportal.craft-host.ru/)**.
2. Войди в свой аккаунт или зарегистрируйся.
3. Для установки используй подходящий файл из этого GitHub-репозитория.

## 📦 Файлы приложения

| Платформа | Файл | Назначение |
|---|---|---|
| 🪟 Windows | `SrepPortal.exe` | Приложение для ПК |
| 🤖 Android | [`SrepPortal.apk`](./SrepPortal.apk) | Установка на Android |
| 🍎 iPhone / iOS | [`SrepPortal.ipa`](./SrepPortal.ipa) | Установка на iPhone совместимым способом |

> APK и IPA доступны в корне репозитория. Для Windows добавь установщик с названием `SrepPortal.exe`, чтобы он отображался в этом списке.

## 🪟 Windows

1. Скачай `SrepPortal.exe` из репозитория, когда файл будет добавлен.
2. Запусти установщик и следуй его инструкциям.
3. Открой приложение и войди в свой аккаунт.

Если Windows предупреждает о неизвестном издателе, запускай файл только в том случае, если доверяешь источнику.

## 🤖 Android

1. Открой [`SrepPortal.apk`](./SrepPortal.apk) в репозитории и скачай файл на телефон.
2. Открой скачанный файл из уведомления или папки «Загрузки».
3. Если система попросит разрешение, разреши установку из этого источника.
4. Нажми **«Установить»** и открой SrepPortal.

Устанавливай APK только из источников, которым доверяешь. Названия настроек могут отличаться в зависимости от версии Android.

### Альтернатива — без APK

1. Открой [SrepPortal](https://srepportal.craft-host.ru/) в Chrome.
2. Нажми меню **⋮**.
3. Выбери **«Установить приложение»** или **«Добавить на главный экран»**, если такая возможность доступна.

## 🍎 iPhone и iOS

### Установка IPA

1. Открой [`SrepPortal.ipa`](./SrepPortal.ipa) в репозитории и скачай файл на компьютер.
2. Используй совместимый инструмент установки и подписи, например [Sideloadly](https://sideloadly.io/).
3. Подключи iPhone к компьютеру и следуй инструкциям инструмента.

**Важно:** установка IPA может потребовать компьютер, Apple ID и периодическое обновление подписи. Установка зависит от устройства и версии iOS.

### Установка без IPA

1. Открой [srepportal.craft-host.ru](https://srepportal.craft-host.ru/) в Safari.
2. Нажми **«Поделиться»**.
3. Выбери **«На экран „Домой“»**, затем нажми **«Добавить»**.

Этот способ добавляет ярлык сайта и не требует установки IPA.

## 🔔 SrepPush — уведомления

Открой **[SrepPortal](https://srepportal.craft-host.ru/)** и проверь доступные настройки уведомлений.

Поддержка push-уведомлений зависит от браузера, устройства и настроек сайта. На iPhone веб-push требует совместимой версии iOS и, как правило, добавления сайта на экран «Домой». Для отдельных приложений могут действовать дополнительные требования.

## 🛡️ Безопасность

- Скачивай файлы только из репозитория проекта или другого официального источника.
- Не передавай пароль и коды подтверждения другим людям.
- Проверяй разрешения, которые запрашивает приложение.
- Сообщай о проблемах через доступные каналы проекта.
